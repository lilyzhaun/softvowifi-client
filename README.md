# SoftVoWiFi client source candidate

This is an App-only source snapshot candidate for development, not a complete VoWiFi distribution or a production release. It retains the existing drag and liquid refraction UI. The source set includes `app/manager/` (manager and shared code, Gradle wrapper, schemas and tests), `app/observer/src/` and `app/observer/res/` (both compiled by the Android public template), source fixtures, and the listed public country inputs. The standalone build entry is `app/manager/gradlew -p app/manager`; validation receipts must identify the exact source revision and commands independently of this template.

Public country regeneration uses only `tools/export/country_catalog.py`, `tools/export/build_country_catalog.py`, and `export/country-source/{MccTable.java,LICENSE,NOTICE,PROVENANCE.md}`. The public MCC-to-ISO table provides flag lookup, not carrier policy.

This candidate does not contain or provide a replacement for the private VoWiFi engine, OEM/operator data, KSU/Magisk module, signing material, private history, or CI. A standalone APK without a compatible core cannot provide VoWiFi. Source completeness, buildability, third-party obligations, and the boundary of any combined binary still require separate review. No phone smoke or VoWiFi end-to-end result is claimed here.
